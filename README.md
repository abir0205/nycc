
# NYSDP — Data Science & Engineering Projects

This repository contains a selection of data science, machine learning, and automation projects I developed during my time as **Data and Analytics Director at the New York State Democratic Party** in 2026.

These projects highlight my experience building predictive models, managing large-scale datasets, developing data pipelines, and automating complex workflows using Python, SQL, and cloud technologies.

## Projects

### Volunteer Propensity Model
`Vol_Propensity_Model/`

An XGBoost machine learning model designed to identify individuals most likely to volunteer, using voter and engagement data to improve recruitment targeting.

### Voter Contact Universe
`Phase_2_Universe/`

SQL-based data pipelines that integrate, clean, and segment large voter datasets to create targeted outreach universes for field operations.

### Field Operations Automation
`packetland_personal/`

A Python automation system using Selenium, REST APIs, and Google Drive to generate and distribute approximately 6,400 canvassing packets across 120+ locations, reducing 30–45 hours of manual work to roughly 90 minutes.

## Technologies

**Python | SQL | BigQuery | XGBoost | scikit-learn | Selenium | REST APIs | Google Cloud Platform**
